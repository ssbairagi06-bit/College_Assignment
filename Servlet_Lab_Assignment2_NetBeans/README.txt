HOW TO USE IN NETBEANS (for each assignment)
1. File > New Project > Java Web > Web Application (server: Tomcat / GlassFish).
2. Right-click Source Packages > New > Servlet, name it Assignment1_Sudhangsu (tick "Add information to web.xml" OFF).
   Paste the provided .java over the generated file (keep the class name = file name).
3. Replace index.html under Web Pages with the provided one.
4. Run the project.

Rename YourName everywhere (file, class, name=, urlPatterns, and the links in the .html file).
Servlet API: javax.servlet (Tomcat 9 / older NetBeans). For Tomcat 10+ / GlassFish 6+, change javax.servlet -> jakarta.servlet.
